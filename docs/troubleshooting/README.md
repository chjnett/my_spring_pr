# 트러블슈팅 기록

여기는 SecureFlow를 실습하면서 겪은 문제의 **원본 기록**을 보관하는 곳이다. 모든 기록을 블로그로 발행하지 않는다. 재현 가능하고, 다른 개발자에게도 배울 점이 있으며, 원인과 검증이 갖춰진 항목만 기술 블로그 후보로 발전시킨다.

## 기록 규칙

파일명은 `YYYY-MM-DD-짧은-문제-이름.md` 형식을 쓴다.

```markdown
# 문제 제목

## 한 줄 요약

## 증상

## 재현 조건

## 내가 처음 생각한 원인

## 실제 원인

## 해결 과정

## 검증

## 배운 점

## 블로그 후보 여부
- [ ] 아직 개인 학습 기록
- [ ] 기술 블로그 초안으로 발전 가능
```

대화 중 오류 메시지, 시도한 명령, 예상과 실제 결과를 가져오면 이 형식으로 함께 기록한다.
